# Inika Jhamvar — macOS Portfolio

A premium interactive portfolio that behaves like a modern macOS desktop, built with Next.js 15.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion + GSAP
- Zustand (persisted window/desktop/settings state)
- Lucide icons

## Run

```bash
cd mac-portfolio-next
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Phase 1 features

- Boot screen → orchestrated desktop reveal
- Wallpaper with mouse parallax + noise
- Menu bar with live clock and dropdowns
- Dock with magnification, bounce, running dots
- Window manager (drag, resize, minimize, maximize, focus, traffic lights)
- Desktop icons (drag + grid snap, selection box, context menu)
- Finder (sidebar, breadcrumbs, search, grid/list)
- Terminal (commands, history, autocomplete, typing animation)
- Notes, Sticky, Resume, About, Contact, Trash, Settings
- Custom cursor
- Keyboard shortcuts: ⌘W close, ⌘F Finder, ⌘T Terminal, ⌘N Notes, Esc
